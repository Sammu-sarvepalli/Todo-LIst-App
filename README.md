 TOdo-List-App 

A modern, responsive To-Do List App with Dark Mode & Filters.

**🚀 Live Demo:** https://sammu-sarvepalli.github.io/Todo-LIst-App/

#✨ Features
- ✅ Add / Edit / Delete Tasks
- 🌙 Dark / Light Mode (Saved in LocalStorage)
- 🔍 Filters - All | Pending | Completed
- 💾 LocalStorage Support - Data never lost
- 📱 Fully Responsive for Mobile
- 📅 Live Date & Task Counter
- ✔️ Mark as Completed with Animation

# 🛠️ Tech Stack
- HTML5, CSS3 (Variables for theming)
- Vanilla JavaScript (No Framework)
